# Лабораторная работа №4: Алгоритмы сортировки (C# / Windows Forms)

Программа демонстрирует работу различных алгоритмов сортировки, визуализирует их пошаговое выполнение, а также проводит сравнительный анализ производительности.

## Содержание

Приложение разделено на три вкладки, соответствующие трем заданиям лабораторной работы:

### Задание 1. Внутренняя сортировка
*   **Реализовано 9 алгоритмов**, разделенных на группы:
    *   *Квадратичные/Субквадратичные:* Выбором (SelectSort), Пузырьковая (BubbleSort), Вставками (InsertSort), Шелла (ShellSort), Шейкерная (CocktailSort).
    *   *Усовершенствованные:* Быстрая (QuickSort), Пирамидальная (HeapSort), Слиянием (MergeSort), Гномья (GnomeSort).
*   **Визуализация:** Вывод последовательных шагов сортировки в лог с настраиваемой задержкой (в миллисекундах).
*   **Статистика:** Подсчет и вывод общего количества сравнений и перестановок для каждого запуска.
*   **Генератор:** Быстрое создание массива для проверки.

### Задание 2. Алгоритмы внешней сортировки
*   **Имитация внешней сортировки:** Данные разбиваются на чанки (блоки), сортируются в памяти, а затем сливаются (метод прямого слияния).
*   **Гибкость данных:** Возможность сгенерировать тестовые данные (уникальные страны) или загрузить таблицу из `.txt` файла (разделитель `;`).
*   **Выбор параметров:** Пользователь может выбрать метод сортировки и ключевой атрибут (Название / Население).
*   **Сохранение результата:** Отсортированные данные автоматически записываются в файл `result_sorted.txt` в папке с программой.

### Задание 3. Текст и эксперименты
*   **Обработка текста:** Загрузка `.txt` файла, разбиение на слова, очистка от знаков препинания.
*   **Частотный анализ:** Подсчет и вывод Топ-20 самых часто встречающихся слов.
*   **Эксперименты:** Автоматический замер времени сортировки текстов разного объема (100, 500, 1000, 2000, 5000 слов).
*   **Сравнение:** Сравнение базового алгоритма (BubbleSort / InsertSort) и продвинутого (QuickSort / RadixSort).
*   **Таблица результатов:** Наглядный вывод времени выполнения в виде таблицы.
